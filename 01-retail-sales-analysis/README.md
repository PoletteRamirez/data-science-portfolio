
# Retail Sales Analysis

## Project Overview
This project analyzes a fictional retail sales dataset to identify sales trends, top-performing products, and revenue patterns.

## Tools & Technologies
- Python
- pandas
- Matplotlib
- SQL
- SQLite

## Objectives
- Explore and understand sales data.
- Check missing and duplicate values.
- Calculate total revenue.
- Identify the best-performing products.
- Compare sales across cities.
- Create data visualizations.
- Use SQL queries to analyze sales.

## Dataset
A fictional dataset created for educational and portfolio purposes.
